# Ice nanotube prisms

Prism blocks on the stacked squares are [Ice nanotubes](../tutorials/nanotubes.md). `seams prisms` is the command that counts them.

The same analysis in the engine book is [Quasi-one-dimensional ice](https://docs.dseams.info/tutorials/nanotube.html) and the [confined ice how-to](https://docs.dseams.info/howto/confined-ice.html).
